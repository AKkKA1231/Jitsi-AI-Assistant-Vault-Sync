Team Onboarding & Setup

🎙️ Meetings_AI Assistant & Vault Sync

Run your own meeting copilot in Chrome, Edge, or Brave in under 3 minutes.

🚀
No Local Server or Node.js Required!

This extension is 100% client-side. You do not need to run terminal commands, npm install, or any backend server. Just download the files, load into your browser, and start meeting!

🔑
Required Permissions Checklist
Permission Type Why it is needed
🎙️ Microphone Browser Prompt Captures your local microphone audio for speech-to-text transcription.
🔊 Speaker Audio In-Tab Audio Captures remote participants' voices via DOM audio element mixing.
💾 Storage Extension Manifest Securely stores your Gemini API key and settings in your browser's private local storage.
📌 Tab Capture & Alarms Extension Manifest Captures tab audio and triggers 3-minute crash recovery checkpoints into IndexedDB.
🌐 Host Permissions Extension Manifest Runs on meet.jit.si / Google Meet and connects to Google Gemini API & Google Drive.
1
Download & Unpack the Extension
  1. Download the project folder or clone from GitHub: 
    git clone https://github.com/AKkKA1231/Jitsi-AI-Assistant-Vault-Sync.git
    (Or download the ZIP from GitHub: click Code → Download ZIP, and extract anywhere).
  2. Notice the extension/ folder inside — that is your ready-to-use browser plugin!
2
Load into Chrome / Edge / Brave
  1. Open your browser and navigate to:
    • Chrome: chrome://extensions
    • Edge: edge://extensions
    • Brave: brave://extensions
  2. Turn ON the "Developer mode" toggle in the top-right corner.
  3. Click "Load unpacked" in the top-left toolbar.
  4. Select the extension/ folder.
✅ Done! You will see the "Meetings_AI Assistant" card appear in your extensions list.
3
Enter Free Gemini API Key (Auto-Saved)
  1. Grab a free API key from Google AI Studio (takes 30 seconds).
  2. Click the puzzle icon in your browser toolbar to open the extension popup (or open any Jitsi/Meet call).
  3. Go to the Settings tab (⚙️ gear icon).
  4. Paste your API key into Gemini API Key and click Save Settings.
🔒 Private & Secure: Your key is saved locally in your own browser's storage and is never sent to any third-party server.
4
(Optional) 60-Second Google Drive Setup

To have notes and audio recordings automatically uploaded to a dedicated folder in your personal Google Drive:

  1. Open script.new in your browser.
  2. Copy the Google Apps Script snippet from GOOGLE_DRIVE_SETUP_GUIDE.md and paste it into the editor.
  3. Click Deploy → New deployment → Select Web app:
    • Execute as: Me
    • Who has access: Anyone (Required)
  4. Click Deploy, authorize access (click Advanced → Go to Untitled project (unsafe) → Allow).
  5. Copy your Web App URL and paste it into the plugin's Settings tab under Google Apps Script Webhook URL.
💡 If you skip this step, clicking "Upload to Drive" will simply download the clean Word document (.docx) / Markdown notes and audio file directly to your computer!
5
Joining a Meeting
  1. Join any meeting at meet.jit.si or Google Meet.
  2. Click the floating ✨ AI Assistant button on the right edge.
  3. Click "Start Recording" and grant mic permissions.
  4. View live transcriptions and AI action items. When done, click "Stop" and "Upload to Drive" or "Share to Slack"!
